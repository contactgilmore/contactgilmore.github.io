# Content and URL Contract

Status: active architecture support document  
Owner: Mike Gilmore  
Reconciled: 2026-09-23

## Current source authority

Astro is the accepted production build. Published article source lives under `src/content/blog/`; layouts, routes and styling live under `src/`. The removed Jekyll tree is historical Git provenance only and is not a build input or parallel source authority.

## Protected identities and routes

Original publication dates and public slugs remain compatibility contracts. Current dated Astro articles preserve the established `SRE-tools`, `GTNY-*` and newer article routes through the content schema and catch-all route. `src/pages/we-have-a-blog.astro` preserves the retired introductory-post route.

Article frontmatter must preserve title, original `date`, thumbnail, optional categories/tags, body, images, code blocks and links. Revisions use `updated`; they do not rewrite original publication chronology. Drafts must remain excluded from generated public routes and discovery.

## Public assets and build

Public image paths under `/assets/images/` remain stable where referenced. Production is generated by the lockfile-defined Astro build and deployed through the current GitHub Pages Actions workflow. Jekyll layouts/configuration, root static templates and their CSS/JavaScript are retired and must not be recreated.

## Acceptance

Content changes must pass governance, Astro build, blog identity/integrity checks, internal-link/build-output validation and claim-matching browser tests. Any slug or protected-asset change requires an explicit compatibility route or redirect before merge.
