# Runtime and Workflow

Production output is static HTML/CSS/assets generated by Astro. Build, validation, packaging, and deployment use GitHub Actions and GitHub Pages.

## CI runner contract

This repository is public. Standard GitHub-hosted runners are the default execution environment:

```text
runs-on: ubuntu-latest
```

Do not register or expose private self-hosted infrastructure to ordinary workflows for this public repository. In particular, untrusted fork or pull-request code must never execute on privately managed runners.

Separate private repositories may use self-hosted runners under their own security contracts; that is not this repository's runtime model.

## Current Pages authority

Production publishing is GitHub Actions workflow mode with HTTPS enforced.

```text
production branch: main
site generator: Astro
Pages build type: workflow
public: true
https_enforced: true
production URL: https://contactgilmore.github.io/
```

Production deployment is intentionally manual-only through `.github/workflows/deploy-pages.yml` after owner approval. Normal feature validation occurs through pull requests to `main`.

## Package/runtime direction

Development uses `npm` unless implementation evidence gives a reason to choose another package manager. Dependency count remains intentionally small.

Current stack:

```text
Astro 7+
TypeScript
Markdown/content collections
custom CSS
minimal client JavaScript
GitHub-hosted Actions
GitHub Pages
Playwright browser regression
axe accessibility checks
```

Current source layout centers on:

```text
src/components/
src/content/blog/
src/layouts/
src/pages/
public/assets/
astro.config.mjs
package.json
.github/workflows/
```

Historical article URLs and required `/assets/...` paths remain compatibility contracts and are protected by automated regression checks.
