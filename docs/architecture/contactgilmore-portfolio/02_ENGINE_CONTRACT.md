# Engine Contract

Astro is the page/layout/component engine. TypeScript is used for configuration and content schemas. Plain CSS is the default styling layer.

React/Vue/Svelte are prohibited by default and require a demonstrated interaction need.

Build must be reproducible from a clean checkout. Production must not depend on a database or long-running application process.

Before Jekyll retirement, Astro must render the migrated blog, build successfully, and satisfy URL/content regression gates.
