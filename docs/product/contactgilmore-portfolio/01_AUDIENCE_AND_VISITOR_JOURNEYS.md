# Audience and Visitor Journeys

Primary audiences:

1. Recruiters screening fit and level.
2. Hiring managers evaluating technical/customer-delivery judgment.
3. Technical interviewers seeking credible implementation, API, cloud, reliability, and troubleshooting depth.
4. Professional peers/readers arriving through blog or LinkedIn.

Preferred journey:

```text
identity/value proposition -> proof areas -> selected case studies -> technical projects/writing -> experience/about -> contact/resume
```

The blog archive should be a dedicated destination; the homepage should feature only selected writing.
