# Visual System Hard Standards

- Responsive centered content container; no giant fixed desktop margins.
- Strong typography hierarchy and comfortable reading measure.
- Restrained neutral palette with limited accent use.
- Accessible contrast and visible keyboard focus.
- Consistent spacing scale and card geometry.
- No skill bars/meters, gratuitous gradients, glowing icon walls, or excessive motion.
- Blog article pages prioritize long-form readability.
- Case studies visually outrank lab projects on the homepage.
