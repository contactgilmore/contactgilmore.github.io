# Product Surface and Interaction Rules

Navigation should expose Work, Writing, About/Experience, Resume, and external professional links without crowding.

Homepage interactions should be simple links/buttons with clear states. No interaction should require JavaScript if normal HTML/CSS can provide it.

Mobile layouts are first-class. Cards may stack; typography and spacing should scale fluidly.

Blog archive should support scanning by title/date/topic and should not dump every full excerpt into the homepage.
